▍四、异常与边界口径

· 区域「待补坐标」不影响工单派发，仅影响地图点位展示；
· 超时工单自动升级市级响应并在列表标记「已升级市级」；
· 高危操作（派发 / 转派 / 退回 / 申请办结）仅指挥长可执行，退回与办结需二次确认；
· 评估标准时限沿用《产品优化方案 V1.0》：5 分钟村级响应、30 分钟到场、60 分钟集结、2 小时控制、24 小时核查、3 日归档。

▍五、页面分工与业务动线（本轮规则）

· 告警研判主页面只做汇聚：左栏为统计（告警统计 / 区域统计），右栏为实时告警（研判责任段：待研判 / 核查中 / 待派发，支持状态筛选，条目带研判 / 核查 / 派发倒计时，超时标红；告警一经派发即转出至工单处理页，一经误报驳回即闭环移出），不承载研判动作；
· 点击任一告警信息（实时告警条目 / 卫星遥感告警卡）→ 右侧「告警详情」弹窗 → 底部操作栏常驻四个出口：待核查（指定乡镇值班室 + 核查时限，结果回传后回到研判）、调度（按工单等级带出派发/签收/到场时限与派发对象，并列出就近无人机/摄像头/物资/队伍/联系人）、确认告警 · 一键派发、误报驳回；
· 应急处置以火灾工单为主对象：点击地图「工单点位」可切换不同工单的处置流程，任务清单 / 处置动态 / 力量 / 物资随工单联动；
· 弹窗会带入所点击告警的名称、等级、来源与时间；确认派发仅指挥长可执行且需二次确认，误报驳回需二次确认且不计入工单统计。
